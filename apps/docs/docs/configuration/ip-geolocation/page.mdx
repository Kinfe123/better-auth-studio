# IP Geolocation

The project supports IP geolocation or location-aware session/event metadata.
## What This Is
IP geolocation enriches security and activity views with approximate location context. It usually depends on a provider or database file, so this page separates required config, optional provider tokens, and privacy-sensitive behavior.
## Why It Matters
IP Geolocation matters because it is part of how Better Auth Studio turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.
## Core Concepts
- IP address
- geolocation provider
- GeoLite
- session metadata
- privacy
## Typical Workflow
1. Choose the supported geolocation provider or database source.
2. Configure any required token, endpoint, or local database path.
3. Use location data as supporting context rather than a definitive identity signal.

### Configuration Options
| Option                    | Required | Description                                                                                                                                   |
| ------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `auth`                    | Yes      | Your Better Auth instance                                                                                                                     |
| `basePath`                | Yes      | URL path where studio is mounted                                                                                                              |
| `access.allowEmails`      | No       | Array of admin email addresses                                                                                                                |
| `access.roles`            | No       | Array of allowed user roles                                                                                                                   |
| `access.allowIpAddresses` | No       | IP allowlist for Studio requests. Supports exact IPs and wildcard patterns (example: `192.168.*`)                                             |
| `access.blockIpAddresses` | No       | IP blocklist for Studio requests. Supports exact IPs and wildcard patterns                                                                    |
| `ipAddress`               | No       | IP geolocation for Events/Sessions: `provider` ("ipinfo" \| "ipapi"), `apiToken`, `baseUrl`, optional `endpoint` (ipinfo: "lite" \| "lookup") |
| `lastSeenAt`              | No       | Enable last-seen tracking: `{ enabled: true, columnName?: string }`                                                                           |
| `metadata`                | No       | Custom branding (title, theme)                                                                                                                |
