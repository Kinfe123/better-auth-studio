# Metadata

The project exposes metadata or branding configuration.
## What This Is
Metadata controls how the product presents itself to administrators. This usually includes title, theme, branding, and other non-functional settings that make the embedded experience feel native to the host application.
## Why It Matters
Metadata matters because it is part of how Better Auth Studio turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.
## Core Concepts
- title
- theme
- branding
- labels
- embedded experience
## Typical Workflow
1. Set product-facing metadata in the runtime configuration.
2. Use branding options to match the host application without changing core behavior.
3. Document which metadata is cosmetic and which affects routing or access.
## Detailed Configuration Model
Metadata controls behavior rather than UI copy. The important questions are what decision this configuration helps a developer make, what happens when it is absent, and what runtime behavior changes when it is enabled. This page keeps the mental model ahead of the raw files that mention the setting.

For Better Auth Studio, configuration usually answers practical questions: who can access the product, where it is mounted, which runtime services it depends on, and what optional capabilities are enabled. Each setting is documented in relation to one of those questions.

## Decision Points
- Is the setting required for every installation, or only for a specific framework, adapter, or deployment mode?
- Does the setting affect security, persistence, presentation, integrations, or developer convenience?
- What does a developer verify after changing it?

## Success Criteria
- Readers know when to configure this area and when they can ignore it.
- Readers understand the consequence of a wrong value.
- Readers can connect the setting to a visible product behavior or runtime integration.

## Repository Notes
These notes come from the repository README so the page stays grounded in existing project language.

### Configuration Options
| Option                    | Required | Description                                                                                                                                   |
| ------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `auth`                    | Yes      | Your Better Auth instance                                                                                                                     |
| `basePath`                | Yes      | URL path where studio is mounted                                                                                                              |
| `access.allowEmails`      | No       | Array of admin email addresses                                                                                                                |
| `access.roles`            | No       | Array of allowed user roles                                                                                                                   |
| `access.allowIpAddresses` | No       | IP allowlist for Studio requests. Supports exact IPs and wildcard patterns (example: `192.168.*`)                                             |
| `access.blockIpAddresses` | No       | IP blocklist for Studio requests. Supports exact IPs and wildcard patterns                                                                    |
| `ipAddress`               | No       | IP geolocation for Events/Sessions: `provider` ("ipinfo" \| "ipapi"), `apiToken`, `baseUrl`, optional `endpoint` (ipinfo: "lite" \| "lookup") |
| `lastSeenAt`              | No       | Enable last-seen tracking: `{ enabled: true, columnName?: string }`                                                                           |
| `metadata`                | No       | Custom branding (title, theme)                                                                                                                |
