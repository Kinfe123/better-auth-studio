# Watch Mode

The CLI or runtime can watch files and reload during development.
## What This Is
Watch mode is the development feedback loop. It keeps the product aligned with local configuration changes by monitoring files, restarting or refreshing the runtime, and reducing manual browser refreshes.

Repository context: Automatically reload the server when your auth. ts file changes.  Perfect for development when iterating on your auth configuration.
## Why It Matters
Watch Mode matters because it is part of how Better Auth Studio turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.
## Core Concepts
- file watcher
- reload

## Typical Workflow
1. Start the runtime with watch mode enabled.
2. Edit the auth or studio configuration file.
3. Confirm the server reloads and the browser reflects the updated configuration.

### Using watch Option
Automatically reload the server when your `auth.ts` file changes. Perfect for development when iterating on your auth configuration.

**Example:**

```bash
# Start with watch mode enabled
pnpx better-auth-studio start --watch
```

**How it works:** Monitors your auth config file for changes, automatically restarts the server, and updates the browser UI via WebSocket - no manual refresh needed.
