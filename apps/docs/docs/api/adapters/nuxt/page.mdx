# Nuxt Adapter

The package exposes a Nuxt adapter surface.
## What This Is
The Nuxt adapter is the framework-specific bridge between the host application and this package. It explains how requests enter the product, where the handler is mounted, and which package export developers import when integrating with Nuxt.
## Why It Matters
Nuxt Adapter matters because it is part of how Better Auth Studio turns repository behavior into a usable developer or operator workflow. This page gives readers the mental model first, then uses implementation evidence as supporting context.

1. Import the adapter from the Nuxt-specific package export.
2. Pass the product configuration into the adapter or handler factory.
3. Mount the generated handler at the route expected by the host application.
