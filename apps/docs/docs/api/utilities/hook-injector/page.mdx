## What It Actually Does
- `buildLastSeenSchema(columnName: string): Record<string, unknown>` - Build plugin schema for lastSeenAt (same shape as phoneNumber plugin: user.fields with returned: true). So the adapter includes this field when fetching users, like phoneNumber / phoneNumberVerified.
- `updateUserLastSeenAt(adapter: any, userId: string | undefined, columnName: string): Promise<void>` - Update user's last-seen column using the adapter only. Column name is configurable (e.g. lastSeenAt, last_seen_at).

## Behavior From Source Evidence
- Recognizes evidence markers such as `type`, `model`, `status`.
- Maps detected inputs to normalized values such as `type` -> `date`, `model` -> `user`, `status` -> `success`, `status` -> `failed`.
