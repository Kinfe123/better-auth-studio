# Environment Variables

The repository reads environment variables or provides environment example files.
## What This Is
Environment variable documentation explains which runtime values the project expects, where those values are read, what each variable controls, and what developers should verify before running previews, workers, or production deployments.
## When To Use This
- Use this when environment variables changes how Better Auth Studio runs, connects, or behaves.
- Use it to decide which values are required, optional, or only needed for a specific workflow.
- Verify configuration changes with the smallest command or integration path that exercises them.
## Core Concepts
- environment variables
- runtime secrets
- configuration files
- deployment values
## Typical Workflow
1. Start from example environment files when they exist.
2. Cross-check each variable against the source file that reads it.
3. Separate required runtime values from optional provider, preview, or deployment values.
## What This Controls
Configuration is useful only when readers can connect each value to behavior. Start by deciding whether the value affects credentials, persistence, routing, framework integration, output, or developer convenience.
