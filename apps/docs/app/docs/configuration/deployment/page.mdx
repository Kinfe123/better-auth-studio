# Deployment

Deployment documentation explains how the product runs in previews, staging, and production.
## What This Is
Deployment documentation explains how the project is expected to run outside local development, which platform files are authoritative, and what needs to be verified for preview, staging, and production environments.

If you want to run Better Auth Studio in its own container, this repository includes a Docker setup for the standalone CLI server.
## When To Use This
- Use this when deployment changes how Better Auth Studio runs, connects, or behaves.
- Use it to decide which values are required, optional, or only needed for a specific workflow.
- Verify configuration changes with the smallest command or integration path that exercises them.
