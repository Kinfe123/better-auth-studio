# Configuration

Use this section to find the configuration pages for Better Auth Studio.

## When to Use This Section
Use this section before running Better Auth Studio in a new environment. It explains which values need to exist, what behavior they control, and how to reason about credentials, defaults, deployment settings, and scale controls.

## Available Pages
- [Database Adapters](/docs/configuration/database-adapters) - Database adapters connect the product to the persistence layer used by the host application.
- [Database](/docs/configuration/database) - Database configuration explains persistence, schema, migrations, and runtime readiness.
- [Deployment](/docs/configuration/deployment) - Deployment documentation explains how the product runs in previews, staging, and production.
- [Environment Variables](/docs/configuration/environment) - Environment variables provide runtime secrets, URLs, provider settings, and deployment values.

## Reading Order
- Identify which values are required for every run and which are optional overrides.
- Treat credentials and destructive scale controls as production-sensitive settings.
- After changing configuration, rerun the smallest workflow that proves the new value is being used.
