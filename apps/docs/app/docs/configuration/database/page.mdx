# Database

Database configuration explains persistence, schema, migrations, and runtime readiness.
## What This Is
Database documentation explains how the project connects to persistence, which schema or migration files matter, and what has to be ready before runtime features read or write state.
## When To Use This
- Use this when database changes how Better Auth Studio runs, connects, or behaves.
- Use it to decide which values are required, optional, or only needed for a specific workflow.
- Verify configuration changes with the smallest command or integration path that exercises them.

## Typical Workflow
1. Identify the database library, schema files, and migration files used by the project.
2. Document required connection variables and migration steps.
3. Explain which runtime features depend on the database being available.
## What This Controls
Configuration is useful only when readers can connect each value to behavior. Start by deciding whether the value affects credentials, persistence, routing, framework integration, output, or developer convenience.
