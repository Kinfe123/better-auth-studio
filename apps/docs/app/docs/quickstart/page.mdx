# Quickstart

This guide takes you from a fresh install to a running studio UI in three steps. You'll need a Better Auth project with an `auth.ts` file and a working database connection.

## 1. Navigate to your project

```bash
cd your-better-auth-project
```

## 2. Install Better Auth Studio

```bash
pnpm add -D better-auth-studio
```

## 3. Start the studio

```bash
pnpm better-auth-studio start
```

The CLI auto-detects your `auth.ts` file from common locations (`auth.ts`, `src/auth.ts`, `lib/auth.ts`, and others). The studio opens automatically at `http://localhost:3002`. If your browser doesn't open, navigate there manually.

> **Note:** Port `3002` is the default so the studio doesn't clash with apps already running on `3000`. You can use any port with `--port`.

## Custom config location

If your auth file lives somewhere non-standard, point the CLI at it directly:

```bash
pnpm better-auth-studio start --config ./src/lib/auth.ts
```

## Common options

```bash
# Run on a different port
pnpm better-auth-studio start --port 4000

# Start without opening the browser
pnpm better-auth-studio start --no-open

# Watch for auth config changes and auto-reload
pnpm better-auth-studio start --watch
```

Once the studio is running, you'll see the dashboard with user and organization counts from your database. From there you can create, edit, or delete users and manage organizations and teams.
