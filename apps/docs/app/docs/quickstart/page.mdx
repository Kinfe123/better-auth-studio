# Quickstart

This guide takes you from a fresh install to a running studio dashboard in the fewest steps possible. You need an existing Better Auth project with a configured `auth.ts` file before you begin.

## 1. Navigate to your project

```bash
cd your-better-auth-project
```

## 2. Install Better Auth Studio

```bash
pnpm add -D better-auth-studio
```

## 3. Start the studio

```bash
pnpm better-auth-studio start
```

The studio auto-detects your `auth.ts` file and opens the dashboard in your browser at `http://localhost:3002`. If you'd rather not open the browser automatically, add `--no-open`.

## 4. Try it without installing

If you just want to evaluate the studio without adding it to `package.json`, run it directly:

```bash
pnpx better-auth-studio start
```

## Common first-run options

Start on a different port if `3002` is already taken:

```bash
pnpm better-auth-studio start --port 4000
```

Point to a config file that isn't in a standard location:

```bash
pnpm better-auth-studio start --config ./src/lib/auth.ts
```

Enable watch mode so the studio reloads automatically when you edit your auth config:

```bash
pnpm better-auth-studio start --watch
```

Once the dashboard is open you'll see a summary of your users, organizations, and teams, along with controls to create, edit, and delete records. To embed the studio inside your application instead of running it as a standalone process, read [Self-Hosting](/docs/self-hosting) and the [Configuration](/docs/configuration) section.
