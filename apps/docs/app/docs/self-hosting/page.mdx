# Self-Hosting

Use this section to find the self-hosting pages for Better Auth Studio.

## When to Use This Section
Use this section when Better Auth Studio needs to run in an environment you own. These pages clarify what belongs to the host application, what the package provides, and what must be verified before production use.

## Reading Order
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.
