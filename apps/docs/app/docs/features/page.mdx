# Features

Better Auth Studio is organized around the chat workflow: receive a Discord question, retrieve Better Auth documentation context, generate a grounded answer, and keep enough recent conversation history for follow-up questions.

## Feature guides
- [Messaging Bot](/docs/features/messaging-bot) - The project runs as a chat bot that listens for user messages and replies inside a messaging platform.
- [Organization Management](/docs/features/organization-management) - Organization management explains teams, members, invitations, and multi-tenant administration.
