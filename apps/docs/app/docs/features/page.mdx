# Features

Use this section to find the features pages for Better Auth Studio.

## When to Use This Section
Use this section to understand the capabilities Better Auth Studio exposes to users, operators, or application developers. Each page explains the outcome first, then links that behavior to setup and reference details.

## Available Pages
- [Dashboard Overview](/docs/features/dashboard-overview) - Dashboard pages give operators a clear view of users, activity, and system health.
- [Developer Tools](/docs/features/developer-tools) - Developer tools help configure, inspect, and generate the pieces needed to run the product.
- [Event Tracking](/docs/features/event-tracking) - Event tracking turns runtime activity into timelines, audit trails, and last-seen context.
- [Organization Management](/docs/features/organization-management) - Organization management explains teams, members, invitations, and multi-tenant administration.
- [Session Management](/docs/features/session-management) - Session management explains active authentication state, sign-in activity, and session controls.
- [User Management](/docs/features/user-management) - User management helps operators inspect accounts, profiles, and account-level actions.

## Reading Order
- Start with the page closest to the workflow you are trying to complete.
- Use setup and configuration pages before running commands in a new environment.
- Use reference pages when you already know the concept and need exact commands, imports, or options.
