# Organization Management

This capability documents the multi-tenant administrative model. It explains how organizations group users, how teams subdivide access, and how membership or invitation actions change what a person can do inside the product.

## How to use it
1. Inspect organizations from the organization list.
2. Open an organization to manage teams, members, and pending invitations.
3. Use create, edit, delete, and bulk seed flows to keep test or production organizations aligned with the auth model.
