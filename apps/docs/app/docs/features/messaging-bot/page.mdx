# Messaging Bot

Better Auth Studio starts in the chat client: listen for a mention or command, gather the context needed to answer, then reply in the same conversation.

This page explains the bot runtime from a user and operator point of view: how messages enter the app, which messages the bot responds to, what feedback it gives while working, and which credentials must be present before it can connect to the platform.

## How to use it
1. Create or configure the bot application in the messaging platform.
2. Set the bot token and any platform client identifiers required by the project.
3. Start the bot process and verify it responds to a mention, command, or direct message.
