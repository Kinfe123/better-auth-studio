# TanStack Start Example

TanStack Start Example shows the shape of a working TanStack Start integration.
## What This Example Shows
TanStack Start Example demonstrates how a TanStack Start host app mounts Better Auth Studio, where configuration lives, and which route or server handler connects the app to the runtime.
## Setup Flow
1. Open the TanStack Start example app and install its dependencies.
2. Review the auth, product, and framework route files before copying the setup.
3. Run the example locally and verify the mounted route loads against the configured runtime.
## What To Look For
- The framework route or handler that mounts the product runtime.
- The auth or product config file that supplies runtime options.
- The package scripts or framework command used to run the example locally.
