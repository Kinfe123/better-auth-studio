# Better Auth Studio

Studio for Better Auth

Better Auth Studio is a messaging product. The docs walk you through how the bot connects to its platform, how people ask questions, and how the project gathers context to send back a useful answer.

New here? Jump to the [quickstart](/docs/quickstart) for a minimal working example, or [installation](/docs/installation) for setup details.
