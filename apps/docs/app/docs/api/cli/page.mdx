# CLI

Use this section to find the CLI pages for Better Auth Studio.

## When to Use This Section
Use this section when you need to run Better Auth Studio from the terminal. The pages here explain command purpose, required configuration, supported flags, safe defaults, and what to verify after the command finishes.

## Available Pages
- [Init Command](/docs/api/cli/init) - The CLI exposes an init command for creating product configuration.
- [Start Command](/docs/api/cli/start) - The CLI exposes a start workflow and runtime flags.

## Reading Order
- Start with the command purpose before copying flags.
- Check required environment variables before running commands that create, mutate, or seed data.
- Prefer the smallest safe script first, then increase scale or concurrency after verification.
